# B3 Task 6 ruling ledger

## Ruling

No new public MCP tool or CLI command is permitted for B3 Task 6. The approved B3 design forbids
public-surface expansion, and the current route inventory contains no aggregate entry point.
`FileMemoryStore.ExecuteMultiMemoryAsync` is an internal Core seam with no public MCP/CLI caller.
Until a separately approved surface exists, aggregate mapping remains available only through the
internal MCP and CLI emit seams used by focused contract tests.

## Boundary requirements

- Preserve existing MCP/CLI envelopes, coordinator and participant IDs, safe evidence filenames,
  typed warnings/reasons, and CLI exit behavior.
- Pass aggregate and participant detail only after stable-text filtering. Reject Unix absolute paths,
  forward-slash and backslash Windows paths, rooted values, traversal, URI/path-like values, and
  foreign-root details. The detail allowlist admits only explicit stable punctuation, alphanumeric
  characters, and ASCII space; CR, LF, tab, all other controls, and non-printing whitespace are
  rejected.
- Keep `CliMcpOutput` source-generated JSON and all single-memory B2 routes unchanged.
- Do not infer aggregate state from journals or exception messages, and do not add remote/HTTP
  surfaces.

## Evidence

The boundary and no-public-entrypoint behavior are pinned by
`MultiMemoryTransactionFacadeTests` and `CliMultiMemoryTransactionTests`. The focused facade/CLI
lane passes with 39 tests; the broader B3/B2 lane passes with 784 tests.
