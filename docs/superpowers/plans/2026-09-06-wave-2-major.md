# Wave 2 — Major Remediation (15 Findings) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. Each task is one TDD cycle: write failing test → run and confirm failure → minimal implementation → run and confirm pass → commit.

Goal: Close all 15 Major findings (contract + ranking + lifecycle) without widening public surface: collapse SearchAll overloads into SearchQuery, materialize candidates once in SearchPipeline, quarantine stale vectors, rebuild scope via the single constructor, deduplicate scorer construction, and make HTTP and file stores answer identically.

Architecture: Wave 2 narrows the search contract so misuse cannot compile: one `SearchAll(SearchQuery)` member replaces five post-filtering overloads, `SearchPipeline.ExecuteAsync` becomes the sole materialization + ranking path that both MCP and server delegate to, and `ILocalStoreLayout` splits local-only path members away from `IMemoryStore`. Ranking parity is enforced by `SearchConformance` running the same corpus against `FileMemoryStore` and `HttpMemoryStore`.

Tech Stack: .NET 10 (`net10.0`), xUnit, `System.Text.Json` source generation (`ScriniaMcpJsonContext`, `CliJsonContext`), `HttpClient` + `POST /api/v1/stores/{store}/search`, `FileRetry`, `DurableFile`, `dotnet build` / `dotnet test` (including `Scrinia.Retrieval.Benchmarks.Tests`).

Spec: docs/superpowers/specs/2026-09-06-review-remediation-design.md

## Global Constraints

- Wave 2 cuts from `main` after Wave 1 merges. No parallel PRs. No finding moves waves to balance size.
- Each change is compile-breaking by intent — next implementation chooses deliberately. No default interface bodies on `IMemoryStore`.
- Every mechanical retype (~53 call sites across SearchAll collapse + ILocalStoreLayout split) is a pure-rename commit with no logic change; contract logic diff is a second commit on top.
- `SearchPipeline` receives explicit contributor args at the edge (`ISearchScoreContributor`, `EntityGraphScoreContributor`) — no ambient lookup inside the pipeline.
- `SaveIndexUnsafe:885` invalidation and migration write-back widening of catch to `(IOException, UnauthorizedAccessException)` are best-effort swallows with idempotent retry comment.
- `WorkspaceRoot` replacement is 7 sites with 4/2/1 post-`Path.Combine` split — verify per-site destination, not just that the property is used.

public static class SearchPipeline
{
    public static async Task<IReadOnlyList<ScoredArtifact>> ExecuteAsync(
        SearchQuery query,
        IMemoryStore store,
        ISearchScoreContributor? contributor = null,
        EntityGraphScoreContributor? graph = null,
        CancellationToken ct = default)
    {
        // Materialize candidates exactly once
        var candidates = query.Candidates ?? store.ListScoped(query.Scopes);
        // Build scorer once (imports M15 dedup)
        var scorer = new WeightedAttributeScorer(store.RankerOptions, query.SupplementalScores, query.EntityGraphScores);
        // Apply context augmentation if present
        string effectiveQuery = query.Context is null ? query.Query : $"{query.Query} {query.Context}";

        // Contributor scores (explicit args, no ambient lookup)
        var supplemental = contributor is not null
            ? await contributor.ScoreAsync(effectiveQuery, candidates, ct)
            : null;

        // Delegate to store's sole SearchAll with fully-built context
        var enriched = query with { Query = effectiveQuery, SupplementalScores = supplemental, Candidates = candidates };
        return store.SearchAll(enriched);
    }
}

namespace Scrinia.Core.Resilience;

public static class RetryPolicy
{
    public static async Task<(HttpResponseMessage? Response, string? Body)> ExecuteAsync(
        Func<Task<HttpResponseMessage>> action,
        CancellationToken ct = default)
    {
        HttpResponseMessage? last = null;
        string? lastBody = null;
        for (int attempt = 0; attempt < 3; attempt++)
        {
            last = await action();
            if (last.IsSuccessStatusCode) return (last, null);
            lastBody = await last.Content.ReadAsStringAsync(ct);
            string logged = lastBody.Length > 500 ? lastBody[..500] + "..." : lastBody;
            if (!IsTransient(last.StatusCode)) return (last, logged);
            await Task.Delay(TimeSpan.FromMilliseconds(100 * (1 << attempt)), ct);
        }
        return (last, lastBody is null ? null : lastBody.Length > 500 ? lastBody[..500] + "..." : lastBody);
    }

    private static bool IsTransient(System.Net.HttpStatusCode code)
        => code is System.Net.HttpStatusCode.TooManyRequests or System.Net.HttpStatusCode.InternalServerError
            or System.Net.HttpStatusCode.BadGateway or System.Net.HttpStatusCode.ServiceUnavailable or System.Net.HttpStatusCode.GatewayTimeout;
}
